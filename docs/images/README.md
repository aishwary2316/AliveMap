# Documentation images

`workspace.jpg` is a native screenshot of AliveMap running actual SUMO on the
Delhi OSM package, captured on 5 November 2026. It is paused after independent
scout reports and a receiving vehicle's route change. The backend is local;
the image does not establish a physical MEC or real 5G transport measurement.
The wall clock includes pauses for inspection and is not a performance benchmark.

`report-delivery.jpg` shows the same paused run at a wider view, with the Radio
inspector listing source reports, tower associations and per-vehicle knowledge.

`incident-tools.jpg` shows the incident editor in that run, including geometry
tools, lifetime, sensing distance and explicit save/publish controls.

Map data and street rendering: © OpenStreetMap contributors. See
[OpenStreetMap copyright](https://www.openstreetmap.org/copyright) and
[project third-party notices](../../THIRD_PARTY_NOTICES.md). Attribution remains
visible in the screenshot. Incident and tower overlays are synthetic.
