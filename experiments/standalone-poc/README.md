# Superseded standalone prototype

The pre-discovery prototype has been retired from the maintained source tree.
Its independent API, fictional grid, tests and duplicate dependency files are
preserved in [Git history at 85a75eb](https://github.com/aishwary2316/AliveMap/tree/85a75eb/experiments/standalone-poc).
It was never an accepted integration design for the physical MEC application.

Use the root README and `laptop.map_launcher --playground` for the supported
workflow. The active compatibility grid in `laptop/scenario/` remains because
baseline integration tests still exercise it. No active module imports this archive.
